## 1.0.0

- First release, for Windows, macOS and Linux. Needs KnobDeck with the companion hub and the
  KnobDeck add-on for Blender (Blender 4.2+, from extensions.blender.org or
  github.com/Knobdeck/knobdeck-blender-companion).
- Play / Pause, Frame dial, Jump to Start / End, Previous / Next Keyframe, Workspace (button and
  wheel), Object Interaction Mode, Viewport Shading, Overlays, X-Ray, Render Image, Render
  Animation, Save, Undo, Redo, Brush Size and Brush Strength dials, Object Transform dial
  (location / rotation / scale, per axis), and a Mode and Object key.
- Keys follow Blender live: playback, frame, overlays, X-ray, brush, transform, mode and object.
