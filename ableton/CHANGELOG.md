## 1.0.0

- First release, for Windows and macOS (Ableton Live has no Linux build). Needs KnobDeck with the
  companion hub, Live 11 or newer, and the KnobDeck Remote Script
  (github.com/Knobdeck/knobdeck-ableton-companion), which setup copies into Live's User Library.
- Transport: Play / Stop, Stop, Continue Playing, Arrangement Record, Session Record, MIDI
  Arrangement Overdub, Automation Arm, Metronome, Loop, Punch In / Out, Capture MIDI, Undo, Redo.
- Tempo dial (BPM) and Tap Tempo (shows the BPM); Previous / Next Locator, Add / Delete Locator.
- Mixer: Master Volume and Track Volume dials (dB), Track Pan dial, Mute, Solo and Record Arm for
  the selected track or a picked one, Selected Track key.
- Session: Launch Scene (selected or picked), Stop All Clips, Select Track / Select Scene dials,
  Tracks and Scenes wheels.
- Device: the selected device's parameters on dials in banks of 8 (Previous / Next Parameter
  Bank keys, or a fixed bank), Selected Parameter dial, Device On / Off, Selected Device key.
- Keys follow Live live: transport, switches, tempo, levels, pan, track switches, selection,
  device and parameter values.
