## 1.2.0

- New Pomodoro action: work / short break / long break every N sessions, configurable lengths,
  the completed-session count on the key, press to start / pause, optional auto-start of the next
  phase; a new Pomodoro Skip / Reset action skips or resets the Pomodoro with the same name.
- Countdown Timer can write the time left to a text file every second (for an OBS text source):
  path, format (mm:ss, h:mm:ss, hh:mm:ss) and text at zero in its settings.
