## 1.1.0

- More launchers: GOG Galaxy and Ubisoft Connect (Windows), Heroic (Epic, GOG, Amazon and
  sideloaded games; every OS) and Lutris (Linux), in Launch Game, the Games Wheel and the store
  filter.
- New Close Game action: asks a game (or any running game the plugin knows) to close, and ends
  it after a few seconds if it doesn't. Only processes started from a known game's install folder
  are touched.
