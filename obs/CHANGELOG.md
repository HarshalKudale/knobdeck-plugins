## 1.4.0

- Split Recording: splits the running recording into a new file (`SplitRecordFile`; OBS 30.2 or
  newer with Automatic File Splitting on, otherwise a clear error).
- Set Text: sets a text source's text (`SetInputSettings`), placeholders expanded; the source
  picker lists GDI+ and FreeType 2 text sources.
- Stream / Record Time: a key showing the stream or recording timecode, updated every second.
